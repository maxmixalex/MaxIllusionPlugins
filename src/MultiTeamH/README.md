# MultiTeamH

Koikatsu 自由 H 的双队实验插件。插件在原生“选择行为”中加入“多P”模式，选择 2F2M 后组成两组可独立切换控制的 1F1M 队伍。

## 使用

- 在“选择行为”中点击新增的“多P”。
- “多P”复用原生“一般”面板，并显示“队1／队2”选择条；每队分别选择一男一女，并分别保存 H 阶段及安全日／危险日。原生“复数”面板不会被修改。
- 四名角色就绪后点击原生确定按钮。
- 点击左上角头像上的“队伍 1 / 2”，或按 `Tab`：切换原生 H UI 当前控制的队伍。头像、进度条、动作菜单和移动轴随当前队伍切换。
- `-`（主键盘或小键盘减号）：显示或隐藏控制面板。
- KK_HCtrl 面板跟随当前焦点队伍显示，两队后台控制状态分别保存。
- 控制面板可分别设置两队的视线、头部是否跟随相机。
- “显示非活动队”：控制另一队是否留在场景中。

两队从原生“一般”自由 H 启动。每队拥有独立的 `HFlag`、`HActionBase` 动作列表、快感、高潮、动画和坐标状态，并行执行完整 H 流程。原生 H UI 只显示并控制当前焦点队。

入口基于“一般”自由 H；动作菜单还追加了带前缀的百合、自慰和 3P 动作。多人动作会临时共用参与角色的动作上下文，切出后恢复各队状态。Darkness 不属于此插件入口。
