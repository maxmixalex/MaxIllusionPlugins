# JuiceControl

**0.2.6**：新增男性前液可选来源开关，和 LoveJuice 0.3.3 的 `MalePre` 接口联动。该来源仅对当前主要男性角色、有效循环动画及达到阈值的原生男性计量生效，默认关闭。

**0.2.5**：新增独立爱液滴落来源开关，使用 LoveJuice 0.3.2 的第七个受限接口键 `Intimate`，由 SkinEffects 的实际 `PussyJuiceBody` 属性驱动。未读取到对应插件状态时不写回或伪造等级。

**0.2.4**：LoveJuice 已接入同一个面板，可操作总开关、五个独立效果来源，并打开 LoveJuice 的详细设置窗。集成采用反射式可选接口；未安装或读取失败时只显示未连接，不修改配置。每次写入必须读回确认，关闭或切换面板后旧控件不能继续生效。

**0.2.3**：补全外部属性的预设读写保护。保存时不再把读取失败写为 0；覆盖已有预设会保留此前已知但暂不可读的字段。应用预设时只写有明确记录的外部字段，旧 XML 未包含的字段不再被自动清零；显式清空仍处理所有可读字段。外部 API 返回不可读、无变化或不接受请求时不再盲目写回；锁定值仅随实际应用成功的字段更新。未应用的外部字段数量显示在状态栏。

Koikatsu 的角色皮肤效果手动编辑器，可调整原生身体部位效果、泪水和脸红等级，并对角色锁定效果值。支持保存角色预设及分组预设，通过运行时兼容代码集成可选的 SkinEffects。

- 0.2.2 区分外部状态读取失败与真实零值；不可读时显示 `—`，自动锁定同步保留已知值并暂停写回，不再用读取失败产生的零值替代已知状态。面板打开时的实机回归仍待验证。
- 默认按主键盘 `0` 显示或隐藏窗口，可在 BepInEx 配置中修改。
- 0.2.1 使用 MaximumUI 0.5.0 的亮色 MDL2 界面，并恢复迁移前的单页排列：角色选择、效果列表、获取/固定/清空/全满、汁液预设、场景预设和 XML 操作。窗口支持拖动、缩放和折叠。
- 每项效果仍为原名称、减号、可点击当前值、加号、锁定框；点击当前值循环，减号和加号在上下限停止。角色与两类预设各有前后切换按钮，下拉选择不会自动应用预设。两类预设均保留 `应用选中`、`新建保存`、`覆盖保存`、`删除选中` 四个原操作。
- 角色选择、效果编辑、锁定及预设逻辑保留在 `JuiceControl.cs`；`JuiceMaximumUi.cs` 对接游戏状态，`JuiceEditorView.cs` 使用真实声明式控件组成界面。
- 效果列表使用 VirtualList；界面按需重建，仅在窗口打开时每 0.2 秒比较一次外部角色和效果状态。预设名称可直接输入，Enter 保存、Escape 取消；文本输入或模态窗口打开时不会触发开关快捷键。
- 角色列表同时比较角色对象身份；同名角色替换会正确刷新。界面回调绑定角色、预设库和目标预设，换库、关闭、禁用或重新打开窗口后不会执行旧界面遗留的操作；正常效果数值刷新保留尚未应用的最后一次编辑。禁用组件会卸载窗口并释放命名对话框目标。
- 默认预设文件为 `BepInEx/config/MaxMixAlex.JuiceControl.presets.xml`，可通过配置修改。
- 支持旧版产生的空根元素及显式 `xsi:nil="true"` 根；载入这些合法空文档不会自动重写文件。
- 载入失败时，预设面板持续显示文件路径和底层解析原因，日志保留完整异常。仍可应用上次成功载入的预设，保存/删除按钮暂时停用；修复文件后点击“重载XML”即可恢复。零字节、截断、非法字符或错误根元素不会被当成空预设覆盖。
- 运行依赖 BepInEx 5、KKAPI；SkinEffects 为可选依赖。

```sh
dotnet build src/JuiceControl/JuiceControl.csproj -c Release
```

输出：`bin/Release/JuiceControl/KK_JuiceControl.dll`。安装时同时提供本次构建的 `MaximumUI.dll` 和 `MaxIllusionPlugins.Common.dll`；不需要安装 Gallery。现有 BepInEx 配置和 XML 格式保留。

实际生产 View 会链接进 MaximumUI 的回归宿主，验证原布局与文字、增减/循环/锁定、命令分发、角色 / 场景预设选择、XML 失败时禁止写入、命名模态和虚拟列表。预览执行生产布局与绘制，覆盖默认、空场景、XML 错误、命名窗口、下拉框及全部滚动位置。逐项对照见 [业务 UI 复刻记录](../../docs/UI-Parity-2026-10-24.md)。SkinEffects 的不同安装版本可能存在成员差异，可从配置与日志检查；真实字体、输入和皮肤效果仍需在对应游戏场景验证。
